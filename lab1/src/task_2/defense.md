Разберём ключевые моменты:

### Конструкция `( Условие -> Тогда ; Иначе )`

Это аналог `if-else` в Prolog:

```prolog
(   translate_ru_en(Ru, EnList)
->  write('Перевод: '), write(EnList), nl
;   write('Слово не найдено.'), nl
)
```

- Если `translate_ru_en` доказуемо → выполняем ветку после `->`.
- Иначе → выполняем ветку после `;`.

### Рекурсивный вызов `main_menu`

После каждого действия снова вызываем `main_menu`, чтобы пользователь мог продолжать работу, пока не выберет `0`.

### Обработка неверного ввода

Последнее предложение:

```prolog
handle_choice(_) :-
    write('Неверный пункт меню. Попробуйте снова.'), nl,
    main_menu.
```

- `_` — анонимная переменная, подходит под **любой** аргумент.
- Ставится **последним**, чтобы сработать только если предыдущие предложения (`1`, `2`, `3`, `0`) не подошли.
- Сообщает об ошибке и снова показывает меню.

> ⚠️ **Важно:** предложение с `_` должно быть **последним** в тексте программы. Prolog проверяет предложения сверху вниз, и если `handle_choice(_)` окажется раньше `handle_choice(1)`, то оно «перехватит» все запросы, и меню не будет работать.
