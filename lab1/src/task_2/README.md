Задание по варианту:

Вариант 3:
* Написать программу, реализующую словарь. В словаре содержится следующая информация: слово и его несколько переводов. Реализовать вывод всего словаря, перевод с русского на английский, с английского на русский (минимум баллов).
Для удобства работы реализовать меню с соответствующими пунктами, предусмотреть пункт для завершения работы и обработку неверного ввода пункта меню.


* ```translator.pro``` - файл с кодом переводчика
* ```test.pro``` - автотест, вставляется в конец программы ```code.pro```
* ```query.pro``` - запросы для ручного тестирования

Как пользоваться "переводчиком"
---

## Запуск и проверка

В поле запроса SWISH введите:

```prolog
main_menu.
```

Дальше работайте по пунктам меню. Пример сеанса:

```
===== СЛОВАРЬ =====
1. Вывести весь словарь
2. Перевод с русского на английский
3. Перевод с английского на русский
0. Выход
Выберите пункт: 1.

дом -> [house,home,building]
кот -> [cat,tomcat]
собака -> [dog,hound]
книга -> [book,volume]
стол -> [table,desk]
окно -> [window,opening]
машина -> [car,automobile,machine]
город -> [city,town]
вода -> [water]
небо -> [sky,heaven]

===== СЛОВАРЬ =====
...
Выберите пункт: 2.
Введите русское слово: кот.
Перевод: [cat,tomcat]

===== СЛОВАРЬ =====
...
Выберите пункт: 3.
Введите английское слово: car.
Перевод: машина

===== СЛОВАРЬ =====
...
Выберите пункт: 5.
Неверный пункт меню. Попробуйте снова.

===== СЛОВАРЬ =====
...
Выберите пункт: 0.
До свидания!
```
